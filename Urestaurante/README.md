# FORJA BRAVA

Landing page estática para un restaurante colombiano de comida rápida, construida con HTML, CSS y JavaScript vanilla.

## Ejecutar localmente

Abre `index.html` directamente en un navegador moderno, o sirve la carpeta desde un servidor local (por ejemplo, la extensión Live Server de VS Code). No requiere instalación de dependencias ni proceso de compilación.

## Personalización

- Edita `PRODUCTS` al inicio de `js/app.js` para cambiar nombres, categorías, descripciones, precios e imágenes de los productos.
- Edita `CONFIG` en `js/app.js` para actualizar ubicación, horario, teléfono y WhatsApp. Configura `whatsappNumber` con el indicativo internacional y el número, sin `+`, espacios ni guiones.
- Reemplaza las imágenes remotas de Unsplash en `js/app.js` y `index.html` por fotografía propia cuando esté disponible. La imagen principal está en `assets/images/hero-forja-brava.png`.
- Los datos de contacto, precios y formulario son demostrativos. El formulario no envía datos y el carrito no procesa pagos.
